Privacy Policy

1. Information We Collect

Kaizen One does not require user registration and does not intentionally collect personally identifiable information through an account system.

Information entered by the user, such as habits, activities, progress records, dates, categories, and related information, is primarily stored locally on the user's Android device.

The application does not intentionally transmit this user-created information to servers operated by Celestial Bear.

2. Local Data Storage

Kaizen One stores application data locally on the user's device in order to provide its core functionality.

This may include:

  • Habits and activities.
  • Progress records.
  • Dates and historical records.
  • Categories and application settings.
  • Statistical information calculated from user records.

This information is used to provide the features of the application, including progress tracking and statistics.

3. Backup and Import/Export

Kaizen One provides functionality to export application data as a backup file and to import previously exported backup files.

When a user exports a backup, the resulting file is stored in a location selected or managed by the user through the Android system and available storage mechanisms.

When a user imports a backup, the application reads the selected file in order to restore the supported application data.

Celestial Bear does not receive or store these backup files on its own servers as part of the application's normal operation.

Users are responsible for the security and handling of exported backup files, including files shared through third-party storage, messaging, or file-sharing services.

4. Statistics and Progress Information

Kaizen One may calculate statistics and progress information using data stored within the application.

These calculations are performed to provide users with information about their recorded habits and activities.

Statistical information generated by the application is not intentionally transmitted to Celestial Bear's servers.
