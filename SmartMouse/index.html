Welcome to Smart Mouse

Smart Mouse is a software solution developed by Celestial Bear that allows an Android mobile device to function as a wireless mouse and keyboard for a computer through a Bluetooth connection.

Smart Mouse consists of two related components:

  • An Android mobile application.
  • A desktop application for Windows and Linux.

Both components are required for the intended operation of the system. Communication between devices is performed through Bluetooth technology and socket-based communication services.
